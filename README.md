# C4D QuadDraw — Retopology Tool for Cinema 4D (2026)

Аналог инструмента **Maya QuadDraw** для Cinema 4D. Позволяет интерактивно создавать полигональную сетку (quads / strips) поверх существующего целевого меша с прилипанием к его поверхности.

---

## 🚀 Возможности

1. **Surface Snapping**:
   - Автоматическое прилипание к поверхности целевого полигонального меша (`TargetSurface`).
   - Привязка к вершинам (`TargetVertex`) и рёбрам (`TargetEdge`) целевого меша при приближении курсора.
   - Автоматический Weld (слияние) при клике вблизи существующей вершины ретопо-сетки (`RetopoVertex`).

2. **Создание квадов (Quad Strips)**:
   - Кликните 4 точки на поверхности — автоматически создаётся quad-полигон.
   - Продолжайте кликать — каждые 2 новых клика продолжают полоску (strip) из предыдущего квада (поведение Maya QuadDraw).
   - Автоматическая ориентация нормалей полигона в направлении целевой поверхности.

3. **Редактирование и удаление на лету**:
   - **Alt + Drag** (или MMB): Перемещение вершины по поверхности целевого объекта (Tweak mode).
   - **Ctrl + Click** по вершине: Удаление вершины и связанных с ней полигонов.
   - **Ctrl + Click** по полигону: Удаление конкретного quad-полигона.
   - **Esc**: Завершить текущую полоску и начать новую.
   - **Backspace**: Отменить последнюю поставленную точку полоски.

4. **Редактируемый меш и целевой объект**:
   - При запуске инструмента выделенный полигональный меш считается **редактируемым объектом**.
   - На редактируемом объекте автоматически создаётся кастомный тег **QuadDraw** (`Tquaddraw`).
   - В свойствах тега **QuadDraw** есть поле **Target Mesh** («Целевой меш»), куда перетаскивается объект для прилипания.
   - **Если цель не указана**: меш редактируется **без прилипания** (вершины и точки свободно позиционируются и перемещаются в плоскости вида).
   - **Если при запуске инструмент ничего не выделено**: автоматически создаётся новый меш `QuadDraw_Retopo` с тегом Phong и тегом QuadDraw.

## ⌨️ Горячие клавиши

| Комбинация | Действие |
|---|---|
| **LMB Click** | Поставить точку на поверхности целевого меша |
| **LMB Drag** | Переместить вершину вдоль поверхности (Tweak) с Weld при наведении на другую вершину |
| **Shift + Hover** | Превью создаваемого квада (подсветка зеленым) |
| **Shift + LMB** | Создать quad-полигон (Maya Blue) |
| **Ctrl + Hover** | Инструмент **Cut** (Insert Edge Loop): превью линии резки рёбер по кольцу квадов |
| **Ctrl + LMB** | Разрезать рёбра / вставить Edge Loop (с интерактивным перетаскиванием слайдером) |
| **Ctrl + Shift + Hover** | Подсветка вершины, цепочки рёбер (Edge Loop) или полигона красным для удаления |
| **Ctrl + Shift + LMB** | Удалить подсвеченный элемент (Vertex / Edge Loop / Polygon) |
| **Esc** | Сбросить активное превью (Cancel) |
